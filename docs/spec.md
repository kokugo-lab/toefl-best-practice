以下の仕様で、新形式TOEFLの4技能練習＋模試Webアプリを作ってください。

# 目的
大学院出願用の英語試験（CEFR B2、TOEFL新形式のバンド4.0〜4.5前後）を目標にする日本人学習者が、
自宅でReading・Listening・Writing・Speakingの4技能を練習し、模試形式で本番の時間感覚をつかみ、
弱点を記録できるアプリ。

# 技術条件
- HTML単一ファイル（CSS・JS込み）＋Netlify Functions（Claude API呼び出し用）
- APIキーはNetlifyの環境変数に置き、ブラウザ側に出さない
- スマホ（縦画面）とPCの両方で使えるレスポンシブ設計
- 学習記録・生成済み問題はlocalStorageに保存（必ずtry/catchで囲み、失敗しても動くようにする）
- 画面の説明文は日本語、出題と回答は英語

# 新形式の構成（この順序と目安時間に合わせる）
- Reading（最大約30分）：新形式の課題形式、2段階のアダプティブ（1段階目の正答率で2段階目の難易度を変える）
- Listening（最大約29分）：講義・会話・短い発話。音声はSpeechSynthesisで男女2声を使い分ける
- Writing（最大約23分）：Build a Sentence／Write an Email／Write for an Academic Discussion
- Speaking（最大約8分）：Listen and Repeat／Take an Interview
- 順序は Reading → Listening → Writing → Speaking
- スコアは各セクション1〜6のバンド、総合は4セクションの平均
※課題名・問題数・時間は新形式の公式情報に沿って作り、画面に「公式と細部が異なる場合あり」と小さく表示する

# 画面構成
1. ホーム：残り日数（本番11/29）、今日のメニュー、直近の苦手分野
2. 練習モード（4技能を個別に）
   - Reading：問題を生成→回答→即採点→言い換え解説と、間違えた原因を表示
   - Listening：音声を再生（再生回数は本番に合わせて制限）→回答→即採点→スクリプトと解説を表示
   - Writing：課題を出す→制限時間つきで入力→添削（構成・文法・語彙・課題への対応）
   - Speaking：質問を音声と文字で出す→MediaRecorderで録音、Web Speech APIで文字起こし→
     本人が文字起こしを修正できる→話した秒数と語数も評価に渡す→録音を聞き直せる
3. 模試モード
   - 開始前に、全セクション分の問題をまとめて生成し、localStorageに保存（途中で通信待ちが出ないようにする）
   - 本番どおりの順序と制限時間で進行し、セクションごとにカウントダウン表示
   - 途中で戻れない・やり直せない（本番の緊張感を再現）
   - 終了後に成績画面を表示：各セクションのバンド（目安）、総合、B2到達度、
     分野別の正答率、間違いの一覧、Writing・Speakingの講評
   - 過去の模試の結果を一覧にして、伸びをグラフで表示
4. 記録・ノート：間違い、未知語、言い換えを自動でノート化し、一覧・検索・復習クイズができる

# Claudeに渡す評価・生成プロンプト（Netlify Function内で使う）
問題生成：新形式の課題形式、学術・キャンパス生活の題材、B2相当の語彙、出力はJSON（問題・選択肢・正解・解説）
Speaking評価（入力：質問・文字起こし・秒数・語数）：
- 出力（JSON）：内容、構成（答え→理由→具体例）、文法、語彙、推定バンド（1〜6、概算と明記）、
  良かった点2つ、改善点2つ、B2らしい言い換え例3つ、模範回答の例
- 発音・抑揚・間は文字起こしから判定できないので、評価しないと明記する
Writing評価：課題への対応、構成、文法、語彙、推定バンド、添削後の文章、直した理由
総合講評：模試の結果から、強み2つ・伸ばしどころ2つを日本語で出力

# 守ってほしいこと
- 評価は励ましを交えつつ具体的に、日本語で書く
- スコアは公式採点と一致しない目安であることを画面に小さく表示する
- 通信エラー時はメッセージを出し、入力済みの回答と進行状況を失わないようにする
- 生成した問題が公式の問題ではなく、新形式を模した練習問題であることを明記する
